How to Use

Preview

Renders your HTML in a temporary live preview window within this tab. Perfect for testing code quickly.

New Tab

Opens your HTML in a brand new browser tab using a blob URL. The tab stays open until you close it, but the blob URL expires when the browser closes completely.

Download

Saves the current HTML as a .html file to your computer. Works even after closing this page.

Export

Exports all your saved snippets as a JSON file. You can then share this file with others or keep it as a backup.

Import

Restores snippets from a previously exported JSON file. This adds them to your existing snippets (no data lost).

💡 Data Storage: All snippets live in your browser's IndexedDB. They persist across tabs & sessions until you delete them. Closing the browser doesn't delete them.
